# notes

A tiny command-line notebook for a lab group: `notes add "..."`, `notes list`, `notes rm ID`. Notes are stored in `~/.notes.json`. Written in an afternoon; three colleagues use it daily.

## The request (from the group leader, 2026-11-05)

"People complain they cannot find old notes any more; there are hundreds now. Can we have tags and a way to search? Also, two of us share a notes file on the group drive and sometimes a note disappears."
