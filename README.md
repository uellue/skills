# skills

A place to keep and share my AI agent skills, as a Claude Code plugin marketplace.

## Install

```bash
claude plugin marketplace add uellue/skills
claude plugin install kaizen@uellue --scope user
```

Or inside a session: `/plugin marketplace add uellue/skills`, then `/plugin install kaizen@uellue`.
To follow updates, turn on auto-update for the `uellue` marketplace under `/plugin` → Marketplaces.

## Plugins

- **kaizen**: continuous improvement of how we work with agents. `/kaizen:debrief` debriefs a Claude Code session or a stretch of work on how the collaboration went, not on what it produced. Cited moments, coaching for the person writing the prompts, proposals with a destination, a usage check from the session transcript, and a history of earlier debriefs so recurring issues are visible. Structure adapted, with thanks, from the MIT-licensed `debrief` skill by Wavez and the `retrospective` plugin by florianbuetow.
